## phone_attribution

查询手机号归属地信息。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `phone_attribution` |
| 分类 | 通信查询 |
| 定价 | 3 MCoin/次 |
| 数据源 | 阿里云市场 - 手机号归属地 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `phone` | string | ✅ | 11 位手机号 |

### 输入示例

```json
{
  "name": "phone_attribution",
  "arguments": {
    "phone": "13800138000"
  }
}
```

### 响应示例

```json
{
  "content": [
    {
      "type": "text",
      "text": "📱 13800138000\n\n🌍 归属地：北京市\n📡 运营商：中国移动\n🏢 号段：1380013\n📞 卡类型：全球通\n\n📊 补充信息：\n• 区号：010\n• 邮编：100000\n• 时区：UTC+8"
    }
  ],
  "isError": false
}
```

### 运营商识别

| 号段 | 运营商 |
|------|--------|
| 134-139, 150-152, 157-159, 182-184, 187, 188 | 中国移动 |
| 130-132, 155, 156, 185, 186, 145 | 中国联通 |
| 133, 153, 180, 181, 189, 177, 173 | 中国电信 |
| 1700, 1701, 1702 | 中国电信虚拟运营商 |
| 1703, 1705, 1706 | 中国移动虚拟运营商 |
| 1704, 1707, 1708, 1709 | 中国联通虚拟运营商 |

### 使用场景

- "13800138000 是哪的号？"
- "这个手机号是移动还是联通？"
- "陌生来电归属地查询"
- "客户手机号归属地校验"

### 注意事项

- 仅支持 11 位中国大陆手机号
- 携号转网用户可能显示转网前的运营商（建议配合 `number_portability` 使用）

## carrier_verify

运营商三要素验证，核验姓名、身份证、手机号的一致性。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `carrier_verify` |
| 分类 | 通信查询 |
| 定价 | 5 MCoin/次 |
| 数据源 | 阿里云市场 - 运营商三要素 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | 姓名 |
| `id_card` | string | ✅ | 身份证号（18 位） |
| `phone` | string | ✅ | 手机号 |

### 输入示例

```json
{
  "name": "carrier_verify",
  "arguments": {
    "name": "张三",
    "id_card": "110101199001011234",
    "phone": "13800138000"
  }
}
```

### 响应示例（验证通过）

```json
{
  "content": [
    {
      "type": "text",
      "text": "✅ 验证通过\n\n📋 验证详情：\n• 姓名：张三\n• 身份证：110101199001011234\n• 手机号：13800138000\n• 运营商：中国移动\n• 归属地：北京市\n• 匹配状态：姓名+身份证+手机号 三要素完全匹配\n\n🔐 验证来源：国家权威数据库"
    }
  ],
  "isError": false
}
```

### 响应示例（验证失败）

```json
{
  "content": [
    {
      "type": "text",
      "text": "❌ 验证不通过\n\n❗ 不匹配项：手机号与身份证不匹配\n\n💡 建议：\n• 确认手机号是否为本人使用\n• 确认身份证号输入正确\n• 如有疑问，请联系运营商"
    }
  ],
  "isError": true
}
```

### 使用场景

- 金融业务实名认证
- 用户注册身份核验
- 支付环节身份确认
- 反欺诈风险识别

### 注意事项

- ⚠️ 涉及个人隐私，调用前请确认符合《个人信息保护法》
- 数据来源于国家权威数据库，准确率高
- 建议前端做初步校验（身份证 18 位、手机号 11 位）

## 🔒 合规说明

- ⚠️ `carrier_verify` 涉及个人敏感信息，请确保：
  - 获得用户明确同意
  - 符合《个人信息保护法》
  - 不存储原始数据，仅做即时验证
  - 保留用户授权凭证

- ✅ `phone_attribution` 和 `number_portability` 是公开信息，合规要求较低
