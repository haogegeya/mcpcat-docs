## invoice_verify

增值税发票真伪验证。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `invoice_verify` |
| 分类 | 验证核验 |
| 定价 | 10 MCoin/次 |
| 数据源 | 国家税务总局发票查验平台 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `invoice_no` | string | ✅ | 发票号码（8 位） |
| `invoice_code` | string | ✅ | 发票代码（10/12 位） |
| `amount` | string | ✅ | 发票金额（保留 2 位小数） |
| `invoice_date` | string | ✅ | 开票日期（YYYY-MM-DD） |

### 输入示例

```json
{
  "name": "invoice_verify",
  "arguments": {
    "invoice_no": "12345678",
    "invoice_code": "011002100311",
    "amount": "100.00",
    "invoice_date": "2026-08-14"
  }
}
```

### 响应示例（真票）

```json
{
  "content": [
    {
      "type": "text",
      "text": "✅ 发票查验通过\n\n📋 发票信息：\n• 发票代码：011002100311\n• 发票号码：12345678\n• 开票日期：2026-08-14\n• 价税合计：100.00 元\n• 不含税金额：88.50 元\n• 税额：11.50 元\n• 税率：13%\n\n🏢 销售方信息：\n• 名称：北京某某科技有限公司\n• 纳税人识别号：91110000XXXXXXXXXX\n• 地址、电话：北京市海淀区xxx路 13800000000\n• 开户行、银行账号：xxx银行 1100000000000000\n\n🏢 购买方信息：\n• 名称：测试企业\n• 纳税人识别号：91110000YYYYYYYYYY\n• 地址、电话：北京市朝阳区xxx路 13900000000\n\n📊 发票状态：正常\n🕐 查验时间：2026-08-14 14:30\n\n✅ 该发票为真实有效的增值税发票"
    }
  ],
  "isError": false
}
```

### 响应示例（假票/异常）

```json
{
  "content": [
    {
      "type": "text",
      "text": "❌ 发票查验不通过\n\n❗ 异常原因：\n• 发票代码、号码、金额、日期不匹配\n• 该发票在税务机关系统中不存在\n\n⚠️ 建议：\n• 请核对发票信息是否填写正确\n• 警惕虚假发票\n• 如有疑问请联系开票方"
    }
  ],
  "isError": true
}
```

### 使用场景

- 财务报销发票核验
- 供应商发票验证
- 业务真实性核查
- 反欺诈风险识别

### 注意事项

- ⚠️ **每天每个发票号只能查验 5 次**（税务系统限制）
- ⚠️ **发票开具后次日才能查验**（非实时）
- ⚠️ 涉及敏感信息，请确保数据传输和存储安全
- ⚠️ 历史发票（5 年前）可能已超出查验期限

## barcode_query

国际条码（EAN/UPC）查询商品信息。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `barcode_query` |
| 分类 | 验证核验 |
| 定价 | 5 MCoin/次 |
| 数据源 | 阿里云市场 - 条码查询 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `barcode` | string | ✅ | 条码（EAN-13 / EAN-8 / UPC-A / UPC-E） |

### 输入示例

```json
{
  "name": "barcode_query",
  "arguments": {
    "barcode": "6901028180173"
  }
}
```

### 响应示例

```json
{
  "content": [
    {
      "type": "text",
      "text": "🔖 条码：6901028180173\n\n📦 商品信息：\n• 商品名称：可口可乐 330ml 听装\n• 品牌：Coca-Cola 可口可乐\n• 规格：330ml\n• 包装：易拉罐\n• 产地：中国上海\n• 厂商：上海可口可乐饮料有限公司\n• 类别：碳酸饮料\n\n📊 条码信息：\n• 条码类型：EAN-13\n• 国家代码：690（中国）\n• 厂商代码：1028\n• 商品代码：1801\n• 校验位：3\n\n💡 备注：商品已在国家物品编码中心注册"
    }
  ],
  "isError": false
}
```

### 条码类型

| 类型 | 长度 | 说明 |
|------|------|------|
| EAN-13 | 13 位 | 国际标准，最常用 |
| EAN-8 | 8 位 | 小商品 |
| UPC-A | 12 位 | 北美 |
| UPC-E | 8 位 | 北美小商品 |
| Code 128 | 任意 | 不支持 |

### 国家代码

| 前缀 | 国家/地区 |
|------|----------|
| 690-695 | 中国大陆 |
| 471 | 中国台湾 |
| 489 | 中国香港 |
| 880 | 韩国 |
| 450-459, 490-499 | 日本 |
| 000-019, 030-039, 060-099 | 美国/加拿大 |

### 使用场景

- "扫一下这个商品条码"
- "这个商品是哪家生产的？"
- "商品条形码是 6901028180173，是什么产品？"
- "商品溯源验证"

### 注意事项

- 商品未注册的条码查不到
- 条码可能对应多个规格，需结合实际商品判断
- 数据来源于中国物品编码中心 + 国际商品数据库

## 🔧 启用方法

1. 登录 [MCPCat 控制台](https://mcpcat.cn/console)
2. 进入「[工具市场](https://mcpcat.cn/console/tools)」
3. 勾选 `invoice_verify` 和/或 `barcode_query`
4. 点击「保存」

## 💡 实战案例

### 案例 1：财务报销

> "我有一张发票要报销，帮我验一下真伪：发票号 12345678，代码 011002100311，金额 100 元，日期 2026-08-14"

**AI Agent 会自动**：
1. 调用 `invoice_verify` 核验
2. 查验通过 → 提示用户可以报销
3. 查验不通过 → 提示用户警惕

### 案例 2：商品溯源

> "我买了一件商品，条码是 6901028180173，帮我查一下是不是正品"

**AI Agent 会自动**：
1. 调用 `barcode_query`
2. 返回商品详细信息
3. 辅助用户判断真伪
