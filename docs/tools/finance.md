## precious_metals

查询贵金属实时行情（黄金、白银、铂金、钯金）。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `precious_metals` |
| 分类 | 金融行情 |
| 定价 | 5 MCoin/次 |
| 数据源 | 阿里云市场 - 贵金属行情 |

### 参数

无（直接查询全品种实时行情）

### 输入示例

```json
{
  "name": "precious_metals",
  "arguments": {}
}
```

### 响应示例

```json
{
  "content": [
    {
      "type": "text",
      "text": "💰 贵金属实时行情\n📅 2026-08-14 14:30:00\n\n🥇 黄金（Au）\n• 国际金价：2,365.80 USD/盎司\n• 人民币金价：553.20 CNY/克\n• 今日涨跌：+0.85% 📈\n• 今日最高：2,371.20\n• 今日最低：2,358.40\n\n🥈 白银（Ag）\n• 国际银价：30.45 USD/盎司\n• 人民币银价：7.12 CNY/克\n• 今日涨跌：+1.23% 📈\n• 今日最高：30.62\n• 今日最低：30.18\n\n🔷 铂金（Pt）\n• 国际铂价：985.60 USD/盎司\n• 今日涨跌：-0.32% 📉\n\n🔶 钯金（Pd）\n• 国际钯价：1,025.30 USD/盎司\n• 今日涨跌：+1.58% 📈\n\n🕐 数据延迟：< 5 分钟\n📊 数据来源：上海黄金交易所 / 伦敦金"
    }
  ],
  "isError": false
}
```

### 品种说明

| 品种 | 代码 | 单位 | 说明 |
|------|------|------|------|
| 黄金 | Au | USD/盎司、CNY/克 | 避险资产首选 |
| 白银 | Ag | USD/盎司、CNY/克 | 工业 + 投资属性 |
| 铂金 | Pt | USD/盎司 | 汽车催化剂、工业 |
| 钯金 | Pd | USD/盎司 | 汽车催化剂、稀缺 |

### 使用场景

- "现在黄金多少钱一克？"
- "白银今天涨了吗？"
- "今天买黄金合适吗？"
- "查询所有贵金属的实时价格"

### 注意事项

- 报价为参考价，实际成交价以银行/金店为准
- 数据每 5 分钟更新
- 国际金价单位是 USD/盎司，国内常用 CNY/克
- 1 盎司 = 31.1035 克

## oil_price

查询全国各省市油价。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `oil_price` |
| 分类 | 金融行情 |
| 定价 | 3 MCoin/次 |
| 数据源 | 阿里云市场 - 油价查询 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `province` | string | ❌ | 省份名（不传则返回全国） |

### 输入示例

#### 查询全国油价

```json
{
  "name": "oil_price",
  "arguments": {}
}
```

#### 查询指定省份

```json
{
  "name": "oil_price",
  "arguments": {
    "province": "北京"
  }
}
```

### 响应示例（全国）

```json
{
  "content": [
    {
      "type": "text",
      "text": "⛽ 全国油价一览\n📅 2026-08-14 调价后\n\n🏙️ 北京市：\n• 92号汽油：8.15 元/升\n• 95号汽油：8.68 元/升\n• 98号汽油：9.36 元/升\n• 0号柴油：7.86 元/升\n\n🏙️ 上海市：\n• 92号汽油：8.11 元/升\n• 95号汽油：8.63 元/升\n• 98号汽油：9.30 元/升\n• 0号柴油：7.82 元/升\n\n🏙️ 广东省：\n• 92号汽油：8.22 元/升\n• 95号汽油：8.90 元/升\n• 98号汽油：9.55 元/升\n• 0号柴油：7.90 元/升\n\n... (更多省份)\n\n📊 本次调价：\n• 92号：+0.12 元/升\n• 95号：+0.13 元/升\n• 0号：+0.11 元/升\n• 调整时间：2026-08-14 00:00\n\n💡 下次调价预测：2026-08-28（涨跌待定）"
    }
  ],
  "isError": false
}
```

### 油品标号说明

| 标号 | 适用车型 | 说明 |
|------|---------|------|
| 92号 | 一般经济型车 | 压缩比 8-9 |
| 95号 | 中高端车 | 压缩比 9-10 |
| 98号 | 豪华车/性能车 | 压缩比 10+ |
| 0号柴油 | 柴油车 | 商用车主流 |

### 使用场景

- "今天 92 号汽油多少钱？"
- "北京和上海的油价对比"
- "下次油价调整是什么时候？"
- "该不该现在去加油？"

### 调价机制

- 国家发改委每 10 个工作日调整一次
- 调整依据：国际市场油价变动
- 调价窗口日 24:00 生效
- 0:00 后加油站按新价执行

## 🔧 启用方法

1. 登录 [MCPCat 控制台](https://mcpcat.cn/console)
2. 进入「[工具市场](https://mcpcat.cn/console/tools)」
3. 勾选 `precious_metals` 和/或 `oil_price`
4. 点击「保存」

## 💡 实战案例

### 案例 1：投资决策辅助

> "现在黄金价格是多少？白银呢？哪个更有投资价值？"

**AI Agent 会自动**：
1. 调用 `precious_metals`
2. 整理各品种价格和涨跌幅
3. 给出参考建议（**不构成投资建议**）

### 案例 2：出行成本计算

> "我要从北京自驾去上海，2000 公里，帮我算下油费"

**AI Agent 会自动**：
1. 调用 `oil_price(province="北京")` 查 92# 价格
2. 根据车型油耗计算（AI 一般会问用户）
3. 给出油费估算
