## weather_query

查询指定城市的天气信息。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `weather_query` |
| 分类 | 生活服务 |
| 定价 | **免费**（每日 50 次免费额度） |
| 数据源 | 阿里云市场 - 天气通 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `cityname` | string | ✅ | 城市名称，如 `北京`、`上海`、`广州` |

### 输入示例

```json
{
  "name": "weather_query",
  "arguments": {
    "cityname": "北京"
  }
}
```

### 响应示例

```json
{
  "content": [
    {
      "type": "text",
      "text": "📍 北京\n🌡️ 温度：18°C ~ 26°C\n☀️ 天气：晴\n🌅 日出：05:42\n🌇 日落：19:15\n💨 风向：东南风\n💪 风力：2 级\n💧 湿度：45%\n👁️ 能见度：15km\n🌬️ 气压：1013 hPa\n\n空气质量：良（AQI 65）"
    }
  ],
  "isError": false
}
```

### 使用场景

- "今天北京天气怎么样？"
- "明天上海会下雨吗？"
- "广州这周末适合出游吗？"
- "出差前查目的地天气"

### 注意事项

- 城市名要准确，支持中文/英文
- 部分城市支持到县级
- 数据每小时更新

## air_quality_query

查询指定城市的空气质量信息。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `air_quality_query` |
| 分类 | 生活服务 |
| 定价 | **免费**（每日 50 次免费额度） |
| 数据源 | 阿里云市场 - 天气通 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `cityname` | string | ✅ | 城市名称 |

### 输入示例

```json
{
  "name": "air_quality_query",
  "arguments": {
    "cityname": "北京"
  }
}
```

### 响应示例

```json
{
  "content": [
    {
      "type": "text",
      "text": "📍 北京 - 实时空气质量\n\n🎯 AQI：65（良）\n\n📊 主要污染物：\n• PM2.5：35 μg/m³\n• PM10：50 μg/m³\n• SO2：8 μg/m³\n• NO2：25 μg/m³\n• O3：78 μg/m³\n• CO：0.6 mg/m³\n\n💡 健康建议：\n各类人群可正常活动。\n\n🕐 发布时间：2026-08-14 14:00"
    }
  ],
  "isError": false
}
```

### AQI 等级说明

| AQI 范围 | 等级 | 颜色 | 健康建议 |
|---------|------|------|---------|
| 0-50 | 优 | 🟢 绿色 | 各类人群可正常活动 |
| 51-100 | 良 | 🟡 黄色 | 敏感人群减少户外 |
| 101-150 | 轻度污染 | 🟠 橙色 | 儿童、老人减少户外 |
| 151-200 | 中度污染 | 🔴 红色 | 一般人群减少户外 |
| 201-300 | 重度污染 | 🟣 紫色 | 建议停止户外运动 |
| >300 | 严重污染 | 🟤 褐红 | 所有人应留在室内 |

### 使用场景

- "今天北京空气质量怎么样？"
- "适合带孩子出门吗？"
- "明天跑步需要注意什么？"
- "过敏患者能出门吗？"

## 🔧 启用方法

1. 登录 [MCPCat 控制台](https://mcpcat.cn/console)
2. 进入「[工具市场](https://mcpcat.cn/console/tools)」
3. 勾选 `weather_query` 和 `air_quality_query`
4. 点击「保存」

## 💡 实战案例

### 案例 1：出行决策

> "我明天要从北京去上海出差，帮我查一下上海明天的天气和空气质量，决定要不要带口罩"

**AI Agent 会自动**：
1. 调用 `weather_query(cityname="上海")`
2. 调用 `air_quality_query(cityname="上海")`
3. 综合分析给出建议

### 案例 2：户外活动规划

> "周末想去爬山，先查一下北京和张家界的天气，选个更好的目的地"

**AI Agent 会自动**：
1. 分别查询两个城市的天气
2. 比较温度、天气状况
3. 给出推荐
