## ip_location

查询 IP 地址的归属地信息。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `ip_location` |
| 分类 | 网络工具 |
| 定价 | 3 MCoin/次 |
| 数据源 | 阿里云市场 - IP 归属地 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `ip` | string | ✅ | IP 地址（IPv4 / IPv6） |

### 输入示例

```json
{
  "name": "ip_location",
  "arguments": {
    "ip": "8.8.8.8"
  }
}
```

### 响应示例

```json
{
  "content": [
    {
      "type": "text",
      "text": "🌐 IP: 8.8.8.8\n\n📍 归属地：\n• 国家：美国\n• 省份/州：加利福尼亚州\n• 城市：山景城（Mountain View）\n• 区县：Santa Clara\n• 运营商：Google LLC\n• ASN：AS15169\n\n🌍 坐标：37.4056, -122.0775\n🕐 时区：UTC-8（太平洋时间）"
    }
  ],
  "isError": false
}
```

### 支持的 IP 类型

| 类型 | 支持 | 说明 |
|------|------|------|
| IPv4 | ✅ | 如 `8.8.8.8` |
| IPv6 | ✅ | 如 `2001:4860:4860::8888` |
| 内网 IP | ⚠️ | 返回"内网地址" |
| 私有 IP | ⚠️ | 10.x.x.x / 192.168.x.x / 172.16-31.x.x |

### 内网 IP 响应

```json
{
  "content": [
    {
      "type": "text",
      "text": "🌐 IP: 192.168.1.1\n\n📍 类型：内网/局域网 IP\n⚠️ 说明：该 IP 为私有地址，无法查询公网归属地"
    }
  ],
  "isError": false
}
```

### 使用场景

- "用户访问来源 IP 是哪里的？"
- "8.8.8.8 是 Google 的 DNS 吗？"
- "我的服务器 IP 归属地是哪里？"
- "异地登录分析"

### 应用场景

#### 1. 用户行为分析
识别用户访问的地理位置，辅助业务决策。

#### 2. 风控反欺诈
- 异常 IP 登录
- 高风险地区访问
- IP 切换频率异常

#### 3. 内容分发
根据 IP 归属地推送本地化内容。

#### 4. 日志分析
批量分析访问日志的地域分布。

## ⚠️ 注意事项

### 1. 精度限制

- 城市级精度：90%+
- 区县级精度：60-70%
- 街道级精度：不支持（隐私原因）

### 2. 代理/VPN 影响

- 通过代理/VPN 访问时，返回的是代理服务器 IP 归属地
- 真实用户 IP 需服务端解析 X-Forwarded-For

### 3. 移动网络特殊

- 中国移动用户 IP 归属地可能跨省
- 4G/5G 切换时 IP 会变化
