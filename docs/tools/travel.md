## train_query

查询火车票信息（车次、余票、时刻表）。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `train_query` |
| 分类 | 出行查询 |
| 定价 | 5 MCoin/次 |
| 数据源 | 12306 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `from` | string | ✅ | 出发站（如 `北京`、`北京西`） |
| `to` | string | ✅ | 到达站（如 `上海`、`上海虹桥`） |
| `date` | string | ✅ | 出发日期（YYYY-MM-DD） |

### 输入示例

```json
{
  "name": "train_query",
  "arguments": {
    "from": "北京",
    "to": "上海",
    "date": "2026-08-15"
  }
}
```

### 座位类型

| 座位 | 缩写 | 说明 |
|------|------|------|
| 商务座 | 商务 | 高铁最高级，可平躺 |
| 特等座 | 特等 | 少数车次有 |
| 一等座 | 一等 | 高铁、动车 |
| 二等座 | 二等 | 高铁、动车主流 |
| 高级软卧 | 高软 | 普速列车 |
| 软卧（一等卧） | 软卧 | 普速列车 |
| 硬卧（二等卧） | 硬卧 | 普速列车 |
| 软座 | 软座 | 普速列车 |
| 硬座 | 硬座 | 普速列车最便宜 |
| 无座 | 无座 | 站票 |

### 车次类型

| 类型 | 字母 | 速度 | 备注 |
|------|------|------|------|
| 高铁 | G | 300+ km/h | 最快 |
| 动车 | D | 200 km/h | 高铁补充 |
| 城际 | C | 200 km/h | 短途城际 |
| 直达特快 | Z | 160 km/h | 大站停靠 |
| 特快 | T | 140 km/h | 较少停靠 |
| 快速 | K | 120 km/h | 较多停靠 |
| 普快 | 普快 | 100 km/h | 站站停 |

### 使用场景

- "明天去上海的高铁有几趟？"
- "查一下北京到广州的火车票"
- "中秋节回家的火车还有票吗？"
- "出差想坐上午的车，推荐几趟"

### 注意事项

- ⚠️ 数据来源于 12306，可能有 5-10 分钟延迟
- ⚠️ 实际余票以 12306 系统为准
- ⚠️ 节假日（春节、国庆）建议提前 30 天预订
- ⚠️ 学生票、残军票等优惠票需到 12306 单独购买

## 🔧 启用方法

1. 登录 [MCPCat 控制台](https://mcpcat.cn/console)
2. 进入「[工具市场](https://mcpcat.cn/console/tools)」
3. 勾选 `train_query`
4. 点击「保存」

## 💡 实战案例

### 案例 1：出行规划

> "明天去上海出差，帮我查最早一班高铁和最晚一班高铁"

**AI Agent 会自动**：
1. 调用 `train_query(from="北京", to="上海", date=明天)`
2. 找出最早和最晚车次
3. 给出建议

### 案例 2：回家决策

> "中秋节想回家，北京到郑州，哪天买票最合适？"

**AI Agent 会自动**：
1. 调用 `train_query` 查询临近日期
2. 分析余票情况
3. 推荐最佳购票时机
