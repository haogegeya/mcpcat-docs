## express_query

查询快递物流信息，支持主流快递公司。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `express_query` |
| 分类 | 物流快递 |
| 定价 | 3 MCoin/次 |
| 数据源 | 阿里云市场 - 快递查询 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `no` | string | ✅ | 快递单号 |
| `com` | string | ❌ | 快递公司代码（不传则自动识别） |

### 快递公司代码

| 代码 | 快递公司 |
|------|---------|
| `shunfeng` | 顺丰 |
| `yuantong` | 圆通 |
| `yunda` | 韵达 |
| `zhongtong` | 中通 |
| `shentong` | 申通 |
| `jd` | 京东 |
| `ems` | EMS |
| `youzhengguonei` | 中国邮政 |
| `tiantian` | 天天 |
| `huitong` | 汇通 |
| `quanfeng` | 全峰 |
| `debang` | 德邦 |
| `fedex` | FedEx |
| `dhl` | DHL |
| `ups` | UPS |

### 输入示例

```json
{
  "name": "express_query",
  "arguments": {
    "no": "SF1234567890",
    "com": "shunfeng"
  }
}
```

### 响应示例

```json
{
  "content": [
    {
      "type": "text",
      "text": "📦 顺丰快递 - SF1234567890\n🚚 当前状态：运输中\n\n📍 物流轨迹：\n\n[2026-08-14 14:30] 北京市 | 已到达【北京顺义中转站】，准备发往下一站\n[2026-08-14 09:15] 北京市 | 快件已从【北京海淀营业点】发出\n[2026-08-13 18:42] 北京市 | 快件已揽收，揽收人：张师傅（138****5678）\n\n📊 预计送达：今天 18:00 前\n🛣️ 运输路线：北京 → 廊坊 → 天津 → 最终目的地"
    }
  ],
  "isError": false
}
```

### 使用场景

- "我的快递 SF1234567890 到哪了？"
- "今天会到吗？"
- "显示签收了，但是没收到，怎么回事？"

### 注意事项

- 单号格式要正确
- 部分快递需要传 `com` 参数（自动识别失败时）
- 物流信息通常 1-2 小时更新一次

## express_query_v2

增强版快递查询，提供更详细的物流节点信息。

### 工具信息

| 项目 | 值 |
|------|-----|
| 工具名 | `express_query_v2` |
| 分类 | 物流快递 |
| 定价 | 3 MCoin/次 |
| 数据源 | 阿里云市场 - 快递查询 V2 |

### 参数

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `no` | string | ✅ | 快递单号 |
| `com` | string | ❌ | 快递公司代码 |
| `phone` | string | ❌ | 收件人手机号（部分快递需要） |

### 与 V1 的区别

| 维度 | V1 | V2 |
|------|-----|-----|
| 物流节点 | 基础节点 | 详细节点（含操作员、电话） |
| 异常提醒 | ❌ | ✅（如派件失败、转退回） |
| 签收凭证 | 简单签收 | 签收照片（如有） |
| 国际件支持 | ❌ | ✅ |
| 预计到达时间 | 有 | 精确（含概率） |

### 输入示例

```json
{
  "name": "express_query_v2",
  "arguments": {
    "no": "SF1234567890",
    "com": "shunfeng",
    "phone": "13800138000"
  }
}
```

### 响应示例

## 🔧 启用方法

1. 登录 [MCPCat 控制台](https://mcpcat.cn/console)
2. 进入「[工具市场](https://mcpcat.cn/console/tools)」
3. 勾选 `express_query` 或 `express_query_v2`
4. 点击「保存」

> 💡 V1 适合基础查询，V2 适合企业级详细跟踪。

## 💡 实战案例

### 案例 1：电商客服

> "用户问订单 #12345 的快递到哪了，单号是 YT9876543210"

**AI Agent 会自动**：
1. 调用 `express_query(no="YT9876543210", com="yuantong")`
2. 返回物流轨迹给客服
3. 客服可直接复制粘贴回复用户

### 案例 2：自动监控

> "我有个重要快递 YT1234567，请每小时查一次，到了告诉我"

**AI Agent（配合定时任务）会**：
1. 每小时调用 `express_query`
2. 状态变化时主动通知用户
