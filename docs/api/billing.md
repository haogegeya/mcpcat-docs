# 计费规则

> MCPCat 平台币（MCoin）计费详细说明

## 💰 MCoin 基础

### 关键参数

| 项目 | 值 |
|------|-----|
| 名称 | MCoin（喵币） |
| 汇率 | **¥1 = 100 MCoin** |
| 最小单位 | 1 MCoin |
| 有效期 | 长期有效（无过期） |
| 退余额 | 支持（联系客服） |

### 为什么用平台币？

✅ **整数计算** — 0.1 元 = 10 MCoin，无精度问题  
✅ **营销活动** — 充值送、签到送、邀请送  
✅ **统一计费** — 不同 API 成本差异大，需要灵活定价  
✅ **扩展性** — 会员等级、积分体系、交易手续费等

## 💸 计费流程

### 标准流程

```
用户调用工具
    ↓
1. 查该工具定价（sell_mcoin）
2. 检查钱包余额 >= sell_mcoin
   ↓ 余额不足 → 返回 -32003
3. 开启数据库事务
   a. 写入 transactions (type=consume, amount=-sell)
   b. UPDATE wallets.balance -= sell
   c. 写入 call_logs (status=pending)
4. 提交事务
    ↓
5. 执行上游 API 调用
    ↓
6a. 成功 → UPDATE call_logs.status=success
6b. 失败 → 退款事务
```

### 关键设计

**预扣 + 失败回滚**

- ✅ **预扣** 在调用前就扣费（避免事后赖账）
- ✅ **失败回滚** 调用失败自动退款
- ✅ **事务化** 三步操作在一个事务里，原子性保证

**核心原则**：

> **可以接受偶尔多退，绝对不能多扣。**  
> 多退是小钱，多扣是信任问题。

## 🔄 退款机制

### 触发场景

| 场景 | 是否退款 | 说明 |
|------|---------|------|
| **空结果** | ✅ | 上游返回 200 但 data 为空 |
| **参数错误** | ✅ | 客户端参数不符合 schema |
| **上游 5xx** | ✅ | 上游服务异常 |
| **上游 4xx** | ✅ | 上游返回业务错误 |
| **网络超时** | ✅ | 超过 30 秒未响应 |
| **余额不足** | ❌ | 调用前就失败，不扣费 |
| **未授权** | ❌ | API Key 无效，不扣费 |
| **工具未启用** | ❌ | 工具未勾选，不扣费 |

### 退款时效

- 实时退款（< 1 秒）
- 在账单中可查 `type=refund` 的记录
- 退款记录包含原始 call_id 关联

### 退款示例

账单中会看到：

| 时间 | 类型 | 金额 | 余额 | 关联 | 备注 |
|------|------|------|------|------|------|
| 08-14 10:00 | 消费 | -3 | 100 | call_abc | express_query |
| 08-14 10:00 | 退款 | +3 | 103 | call_abc | 上游错误 |

## 📊 账单查询

### 控制台查询

登录 [MCPCat 控制台](https://mcpcat.cn/console) → 「账单」

可查询：
- **实时账单**：最近 100 条
- **时间筛选**：按日/周/月
- **类型筛选**：消费/退款/充值/赠币

### 账单字段

每条账单记录包含：

| 字段 | 说明 |
|------|------|
| `id` | 交易 ID |
| `time` | 交易时间 |
| `type` | 类型（消费/退款/充值/赠币） |
| `amount` | 金额（正=增加，负=扣减） |

## 🛡️ 风控保护

### 异常检测

MCPCat 自动检测以下异常行为：

- **短时间大量调用高价工具** → 自动冻结
- **参数注入攻击** → 自动冻结
- **绕过计费尝试** → 永久封禁
- **明显的羊毛党行为** → 限制功能

### 冻结处理

- Key 被冻结后所有调用立即失败
- 控制台可查看冻结原因
- 联系 support@mcpcat.cn 申请解封

## 💡 节省成本建议

### 1. 优先用免费工具

天气、IP 归属是免费的，能用免费就用免费。

### 2. 批量任务用脚本

批量查询时自己写脚本调用 API，比让 AI Agent 一次一次问便宜。

### 3. 利用免费额度

免费工具每日有 50 次额度，超出后才收费。

### 4. 缓存常用数据

变动不大的数据（如贵金属行情）可本地缓存，减少 API 调用。

### 5. 选择性启用工具

只勾选真正需要的工具，AI Agent 不会调用未勾选的工具（避免误调用）。

## 🆘 常见问题

### Q: 余额会过期吗？

不会，MCoin 长期有效。

### Q: 充值后能退吗？

支持，联系 support@mcpcat.cn 申请退款，未消费的 MCoin 可退。

### Q: 为什么我调用失败了还扣费？

可能情况：
- 上游返回 200 但 data 有数据（MCPCat 视为成功）
- 空结果检测规则未覆盖你的场景

联系 support@mcpcat.cn 提供 call_id，可人工核查退款。

### Q: 怎么查看免费额度剩余？

调用免费工具时响应 Header 包含：
```
X-Free-Quota-Used: 5
X-Free-Quota-Limit: 50
X-Free-Quota-Reset: 2026-08-15 00:00:00+08:00
```

### Q: 余额不足会欠费吗？

不会，余额不足时直接返回错误，不会欠费。
