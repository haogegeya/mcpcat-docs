## 🚀 发布建议

### 知乎（最值得投入）

**最佳发布时间**：工作日 20:00-22:00

**发布流程**：
1. 打开 https://zhuanlan.zhihu.com/write
2. 标题：直接复制 `zhihu-article.md` 里的
3. 正文：复制 markdown 内容，知乎编辑器支持渲染
4. 封面：去 https://mcpcat.cn 截首页，或用 https://www.canva.com/ 做个 1200x630
5. 标签：复制文末的 `#MCP #MCP协议 ...`
6. 投专栏：建议「AI 工具」「效率工具」「程序员」

**配图**（强烈建议配图，否则阅读量减半）：
- 封面图：10 个 MCP logo 九宫格（MCPCat 中间最大）
- 配图 1：MCPCat 控制台工具市场截图
- 配图 2：Claude 调用 MCPCat 的配置截图
- 配图 3：失败自动退款的账单截图

**互动策略**：
- 前 20 条评论必回
- 对质疑"和某某区别"的耐心解答
- 评论区引导加微信群（私域转化）
- 主动 highlight 关键信息

---

### 掘金（技术向）

**最佳发布时间**：工作日 9:00-11:00 或 20:00-22:00

**发布流程**：
1. https://juejin.cn/draft/new
2. 标题用 `juejin-article.md` 里的
3. markdown 直接粘贴，自动渲染
4. 分类选「后端 → AI → 开发工具」
5. 标签：复制文末的

**掘金特色**：
- 支持代码块语法高亮
- 表格渲染好看
- 技术读者多，长文接受度高

---

### V2EX（流量+互动）

**最佳发布时间**：工作日 10:00-12:00 或 21:00-23:00

**发布流程**：
1. https://v2ex.com/newtopic
2. 节点选「创造者」
3. 标题：`v2ex-post.md` 里的
4. 正文：直接复制 markdown（V2EX 也支持）
5. 文末互动问题要保留

**V2EX 特点**：
- 极客密度高，反馈质量好
- 适合做技术讨论和反馈收集
- 流量大但转化看文笔

---

### 即刻（轻松向）

**最佳发布时间**：随时（晚 8-11 点流量好）

**发布流程**：
1. 打开即刻 App
2. 「发动态」
3. 复制 `jike-post.md` 内容
4. 加话题标签

**即刻特点**：
- 短平快
- 互联网圈密度高
- 适合做品牌曝光

---

### 小红书（流量大）

**最佳发布时间**：12:00-14:00 / 19:00-22:00

**发布流程**：
1. 打开小红书
2. 「+」→「图文」
3. 标题：`xiaohongshu-post.md` 里的
4. 正文：复制内容
5. 配 3-5 张图（必须配图）
6. 加话题标签

**配图要求**（小红书没图基本没流量）：
- 封面图：1200x1600 竖屏
- 工具图标拼图
- 接入流程截图
- 工具列表截图

**小红书特点**：
- 流量大但用户偏 C 端
- 适合做品牌曝光
- 转化靠评论区引导

## 💡 注意事项

### 通用

- **不要同一时间 5 个平台都发** — 留 2 小时间隔，让每篇都有首发流量
- **引导关注/加群** — 知乎文末、小红书评论、即刻置顶都可以
- **预留 1 小时回评论** — 发布后 1 小时是关键互动期
- **配图一定要做** — 无图 = 无流量

### 知乎特别提醒

- **不要直接发外链** — 知乎会限流，把 https://mcpcat.cn 放在评论区第一条
- **不要用诱导关注话术** — 会被折叠
- **不要刷赞** — 风控严

### 小红书特别提醒

- **必须配 3+ 张图** — 否则阅读量减 80%
- **标题要短** — 18 字以内最佳
- **正文分段** — 用 emoji 分段，别一大段
- **不要硬广** — 用"姐妹们""兄弟们"等亲昵称呼
